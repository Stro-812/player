# Инструкция для Claude Code: выложить сайт книги «Не про бег» на Netlify

Ты — Claude Code на компьютере партнёра Юрия Строфилова. Партнёр не программист. Сделай всё сам,
командами в терминале. От партнёра нужны только два действия: войти в Netlify в браузере
и добавить одну запись DNS на сайте Porkbun. Объясняй ему простыми словами и по одному шагу.

Цель: сайт книги из папки `site/` этого архива открывается по адресу **__SITE_URL__**.

## Что нельзя делать

- **Не трогать сайт stro.coffee.** Это отдельный проект Netlify (`glittery-haupia-bb2c0c`).
  Не выкладывай в него, не связывай с ним папки, не меняй его настройки.
- **Не менять другие записи DNS** домена stro.coffee в Porkbun. Добавляется ровно одна новая запись.
- **Не менять файлы в `site/`.** Сайт уже собран: адреса проставлены, сборка не нужна.
  Если что-то не работает, опиши проблему партнёру, он передаст Юрию.

## Что в архиве

- `site/` — готовый статический сайт: HTML, CSS, JS, картинки, EPUB и PDF книги, RSS-лента `podcast.xml`.
  Сборка не нужна, `netlify.toml` это и говорит Netlify.
- Аудио в архиве нет. Плеер и лента берут MP3 по полным адресам `https://your.s10.run/audio/01.mp3 … 11.mp3`,
  поэтому от того, где лежит сайт, звук не зависит.

## Шаги

### 1. Подготовка

1. Распакуй архив, если он ещё не распакован, в `~/ne-pro-beg-netlify` и работай в этой папке.
2. Проверь Node.js: `node -v`. Нужна версия 18 или новее. Если Node нет, установи (`brew install node`
   на Mac) и скажи партнёру, что ставишь.
3. Проверь сайт:
   - есть `site/index.html`, `site/glava/01/index.html`, `site/podcast.xml`;
   - `grep -c "your.s10.run/audio" site/assets/js/data.js` даёт 11;
   - `grep -rn "__SITE_URL__" site` ничего не находит.

### 2. Вход в Netlify

1. `npx netlify-cli@latest login` — откроется браузер. Попроси партнёра войти **в тот же аккаунт Netlify,
   где сайт stro.coffee**, и нажать «Authorize».
2. `npx netlify-cli@latest sites:list` — в списке должен быть проект `glittery-haupia-bb2c0c`
   (stro.coffee). Если его нет, партнёр вошёл не в тот аккаунт: попроси выйти и войти в нужный.

### 3. Новый проект и выкладка

1. Создай **новый** проект, не связывая с ним папку:
   `npx netlify-cli@latest sites:create --name ne-pro-beg --disable-linking`
   Если имя занято, попробуй `ne-pro-beg-book`, потом `stro-book`. Если Netlify спросит команду (team),
   выбери ту же, где проект stro.coffee.
   Запиши имя и id нового проекта в файл `~/ne-pro-beg-netlify/netlify-site.txt`.
2. Выложи:
   `npx netlify-cli@latest deploy --prod --no-build --dir site --site <имя проекта> --message "Сайт книги"`
3. Проверь адрес `https://<имя проекта>.netlify.app`:
   - `curl -s -o /dev/null -w "%{http_code}\n"` для `/`, `/glava/01/`, `/podcast.xml`, `/files/ne-pro-beg.pdf` — везде 200;
   - звук: `curl -sI -H "Range: bytes=0-1" https://your.s10.run/audio/01.mp3` — должно быть `206` и `Accept-Ranges: bytes`;
   - попроси партнёра открыть адрес в браузере, нажать «Слушать» и убедиться, что звук идёт.

### 4. Адрес __SITE_URL__

1. Привяжи домен к новому проекту (id — из шага 3):
   `npx netlify-cli@latest api updateSite --data '{"site_id":"<id>","body":{"custom_domain":"book.stro.coffee"}}'`
2. Попроси партнёра добавить запись DNS. Продиктуй ему по шагам:
   - открыть https://porkbun.com и войти;
   - Domain Management → у домена **stro.coffee** нажать **DNS**;
   - добавить запись: **Type** `CNAME`, **Host** `book`, **Answer** `<имя проекта>.netlify.app`, **TTL** `600`;
   - нажать **Add**. Остальные записи не трогать.
3. Проверяй, когда запись появится:
   `curl -s "https://dns.google/resolve?name=book.stro.coffee&type=CNAME"` — в ответе должно быть `<имя проекта>.netlify.app`.
   Обычно это занимает от нескольких минут до часа.
4. HTTPS Netlify выпускает сам после того, как запись появилась. Если через 30 минут `https://book.stro.coffee`
   не открывается, запусти:
   `npx netlify-cli@latest api provisionSiteTLSCertificate --data '{"site_id":"<id>"}'`
5. Финальная проверка: `https://book.stro.coffee/`, `/glava/01/`, `/podcast.xml` отвечают 200.
   Попроси партнёра открыть сайт на телефоне и включить звук.

### 5. Отчёт

Скажи партнёру простыми словами: адрес сайта, что проверено, что работает, что нет.
Попроси переслать этот отчёт Юрию.

## Обновление сайта потом

Юрий пришлёт новый архив. Распакуй его, папку `site/` положи на место старой и выложи **в тот же проект**:
`npx netlify-cli@latest deploy --prod --no-build --dir site --site <имя из netlify-site.txt>`
Новый проект не создавай. Домен и DNS настраивать заново не нужно.

## Если что-то не так

- **Нет звука, а сайт открывается.** Проблема не в Netlify. Проверь `curl -sI -H "Range: bytes=0-1" https://your.s10.run/audio/01.mp3`.
  Если ответ не 206, сообщи Юрию: файлы лежат на его сервере.
- **Сайт без стилей или картинок.** Убедись, что выложена именно папка `site` (`--dir site`), а не архив и не папка уровнем выше.
