# Сайт книги «Не про бег»

Статический сайт без сборки: HTML, CSS и JavaScript. Подходит для GitHub Pages как есть.

## Что внутри

```
index.html                 главная: все разделы и плеер аудиокниги
read.html                  первая глава «Марафон и поэты» для чтения онлайн
podcast.xml                RSS-лента подкаста (Really Simple Syndication — адрес для подкаст-приложений)
podcast/chapters/NN.json   главы каждого эпизода для подкаст-приложений (формат Podcasting 2.0)
assets/css/site.css        стили
assets/js/site.js          плеер и интерактив
assets/js/data.js          эпизоды и главы для плеера, собирается скриптом из data/
assets/img/                обложка, рисунок бегуна, иллюстрации учеников, картинка для соцсетей, иконки
data/episodes.json         11 эпизодов: адрес, длительность, размер
data/chapters-audio.json   начала 45 глав внутри эпизодов
tools/build_data.py        пересобирает data.js, podcast/chapters и podcast.xml из data/
files/                     сюда кладутся EPUB и PDF
.nojekyll                  чтобы GitHub Pages отдавал файлы как есть
```

Аудио не хранится в репозитории: плеер и лента берут MP3 с `https://your.s10.run/audio/01.mp3 … 11.mp3`.

## Что заполнить перед публикацией

1. **Адрес сайта.** Во всех файлах заменить метку `__SITE_URL__` на итоговый адрес без слеша в конце: `index.html`, `read.html`, `podcast.xml`, `tools/build_data.py`. Адрес известен после включения GitHub Pages или после настройки своего домена.
2. **Почта владельца подкаста.** В `podcast.xml` и `tools/build_data.py` заменить `__OWNER_EMAIL__`. Спросить у Юрия, какой адрес указать: он виден в ленте публично, по нему Apple Podcasts подтверждает владельца.
3. **EPUB и PDF.** Положить файлы в `files/` под именами `ne-pro-beg.epub` и `ne-pro-beg.pdf`. Спросить у Юрия, где они.
4. **Обложка подкаста.** Плеер и лента ждут `assets/img/podcast-cover.jpg`. Взять обложку, встроенную в MP3:
   `ffmpeg -i https://your.s10.run/audio/01.mp3 -an -c:v copy assets/img/podcast-cover.jpg`
   Apple Podcasts требует квадрат от 1400 до 3000 px, JPEG или PNG. Если обложка меньше или не квадратная — сообщить Юрию.
5. **Сервер с аудио.** Проверить, что your.s10.run отдаёт MP3 частями:
   `curl -sI -H "Range: bytes=0-1" https://your.s10.run/audio/01.mp3`
   Должно быть `206` и `Accept-Ranges: bytes`. Без этого на iPhone не работают воспроизведение и перемотка.

## Публикация на GitHub Pages

- Имя репозитория и аккаунт — спросить у Юрия. Свой домен, если нужен, — тоже.
- Опубликовать содержимое этой папки в корне ветки `main`, включить Pages: Settings → Pages → Deploy from a branch → `main` / root.
- Для своего домена — файл `CNAME` с доменом и запись у регистратора.

## Проверка после публикации

- Плеер на iPhone (Safari) и Android (Chrome): воспроизведение, перемотка ползунком и кнопками −15/+30, переход по главам, скорость, экран блокировки, продолжение с места после перезагрузки страницы.
- Ссылки «Слушать главу» в «Шести звёздах» включают нужный эпизод с нужной минуты.
- Прямая ссылка на место в книге работает: `…/#ep=5&t=2933`.
- `podcast.xml` проходит проверку валидатором RSS для подкастов.
- Картинка `og.jpg` подтягивается в превью ссылки в Telegram.

## Как обновить главы или эпизоды

Поправить `data/chapters-audio.json` или `data/episodes.json`, затем:

```
python3 tools/build_data.py
```

и снова заменить метки `__SITE_URL__` и `__OWNER_EMAIL__` в `podcast.xml`.

## Открытые вопросы по аудио

- **Эпизод 10.** Первые слова главы 40 «Письма и калоши» звучат в самом конце эпизода 9, на 01:21:33. В эпизоде 10 глава пока отмечена с 00:00:00. Нужно проверить, с какой секунды она там на самом деле начинается.
- **Эпизод 11.** Начало главы 42 «Ярославль и корова» в записи отсутствует: эпизод 10 заканчивается вместе с главой 41, эпизод 11 начинается с середины главы 42. Юрий допишет недостающий кусок.
- **Эпизод 11 на сервере — 64 кбит/с**, остальные — 96. Похоже, на сервере лежит версия до ремастера. Если файл заменят, перемерить начала глав эпизода 11 и обновить `data/`.
