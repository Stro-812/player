# Не про бег — сайт-плеер подкаста

Полное ТЗ: `docs/TZ-etap-1.md`. Сейчас этап 1: статический сайт без входа и сервера для партнёров.
Проект самостоятельный и не связан с другими репозиториями владельца.

## Команды

- `npm run dev` — локальный сервер; `npm test` — Vitest; `npm run typecheck`; `npm run build` — сборка в `dist/` (+ лента, если задан `FEED_SLUG`).
- `npm run pack` — архив для программистов: собранный сайт + `deploy/README-DEPLOY.md`.
- `npm run probe -- <папка с MP3>` — длительность и размер в `episodes.json` через ffprobe.
- `scripts/audio.sh` — команды ffmpeg/ffprobe для MP3. **Перед запуском перекодирования показать команду владельцу.**

## Правила, которые сохраняют путь к этапу 2

1. Ссылка на аудио — только через `getAudioUrl(episode)` (`src/audio/getAudioUrl.ts`). Ошибка загрузки → `getAudioUrl` заново и продолжение с `currentTime`, паузы 2, 5, 10 с.
2. Позиции — только через `progressStore` (`get`, `set`, `markDone`, `all`), никаких прямых обращений к `localStorage`.
3. Эпизоды — только из `src/data/episodes.json`. В разметке ничего не хардкодить. `durationSec` и `bytes` не вписывать руками.
4. Кнопки «Слушать» ведут на `#/play`.

## Нельзя

- Web Audio, декодирование в JS, HLS, MSE. Один `<audio>` на приложение, `preload="metadata"`, без `crossorigin`.
- Перехватывать в Service Worker запросы к MP3 или с заголовком Range.
- Подключать Google Fonts и другие сторонние CDN: шрифты лежат в `public/fonts`.
- React, Vue и другие UI-фреймворки.
- Класть MP3 в репозиторий; класть ключи хостинга в репозиторий (только переменные окружения).

## Дизайн

Токены цветов — в `src/ui/styles.css`. Белый на `coral` — только текст от 19 px жирным или от 24 px обычным, мельче — `deep`.
Нажимаемые элементы ≥ 48 px, главная кнопка во всю ширину, 96 px. Montserrat 800–900 — заголовки, Sofia Sans Extra Condensed 800 — цифры и надпись, Golos Text — текст.
Иконки и обложки в `public/icons`, `public/cover-*.jpg` — временные (`scripts/make-placeholder-icons.py`), ждут финальных от владельца.

## Домены

Плеер открывается на s10.run и your.s10.run (папка — на выбор программистов). `audioBase` = `/audio/`:
звук всегда с того домена, где открыт плеер. Все пути сборки относительные (`base: './'`), сайт не привязан к корню домена.

## Код

TypeScript strict, Vite, маршруты по hash. Комментарии и тексты интерфейса — по-русски.
